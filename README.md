# qPCR Calculator

计算QPCR的简易小工具：输入 Ct 值，自动计算 ΔCt、ΔΔCt 和相对表达量 (2^-ΔΔCt)。

纯静态页面，所有计算在浏览器本地完成，不上传任何数据。直接打开 `index.html` 即可使用。

## 功能

- 每行输入样品名、内参 Ct、目的基因 Ct，实时计算结果
- 可添加多个样品和多个目的基因列
- 每行可选对照样品，以该行的 ΔCt 作为基准
- 结果表可一键复制为制表符分隔格式，直接粘贴到 Excel
- 支持打印或导出 PDF

## 计算公式

```
ΔCt = Ct(目的基因) - Ct(内参基因)
ΔΔCt = ΔCt(处理组) - ΔCt(对照组)
Fold Change = 2^(-ΔΔCt)
```

前提是目的基因和内参基因的扩增效率都接近 100%（效率 E ≈ 2）。
